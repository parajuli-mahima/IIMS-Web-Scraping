# IIMS Web Scraping Project

## Overview

This project contains Jupyter notebooks for scraping and extracting data from the IIMS website. The notebooks demonstrate web scraping techniques using Python, including data collection, table extraction, and data processing.

## Files

### IIMS.ipynb

* Performs web scraping from the IIMS website.
* Extracts and processes relevant information.
* Demonstrates data cleaning and analysis.

### IIMS_Doc_Table_Scraping.ipynb

* Extracts tabular data from IIMS documents/web pages.
* Processes and organizes the extracted data into a structured format.

## Technologies Used

* Python
* BeautifulSoup
* Selenium
* Pandas
* Requests

## Project Objective

The objective of this project is to practice web scraping, data extraction, and data preprocessing techniques using Python.
